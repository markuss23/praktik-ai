# Security

Please do not report vulnerabilities in public issues. Use GitHub's private reporting instead: **Security → Report a vulnerability** in this repository.

We will respond as soon as possible and keep you updated until the issue is resolved.

---

Bezpečnostní chyby prosím nehlas ve veřejných issues. Použij soukromé hlášení na GitHubu: **Security → Report a vulnerability** v tomto repozitáři.
